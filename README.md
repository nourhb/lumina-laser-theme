# Lumina — Laser & Aesthetic Clinic Block Theme

**Lumina** is a clean, premium WordPress block theme built for laser and aesthetic clinics — laser hair removal, skin rejuvenation, acne therapy, and med-spa services. Crisp clinical whites, soft teal and violet accents, and trust-building patterns make it easy for a clinic to look established online from day one.

## Features

- **Full Site Editing** — edit headers, footers, templates and every pixel with the block editor
- **Complete theme.json design system** — clinical white/mist/teal/violet/slate palette, Fraunces display + Manrope body, fluid type scale, soft shadows
- **10 hand-built block patterns** — hero, treatments grid with pricing, device technology, specialists team, results testimonials, animated stats, packages, gallery, laser FAQ, consultation CTA
- **"Noir" style variation** — one-click dark premium mode
- **Photo-rich by default** — real clinic photography wired into hero, treatments, team, and gallery patterns
- **Motion with manners** — scroll reveals, animated counters; all disabled under `prefers-reduced-motion`
- **Accessibility** — skip link, visible focus states, semantic landmarks
- **Translation-ready** — `lumina` text domain

## Installation

1. Download or clone this repository.
2. Copy the `lumina-laser-theme` folder into `wp-content/themes/` (rename the folder to `lumina` if you like).
3. In WordPress, go to **Appearance → Themes** and activate **Lumina**.
4. Open **Appearance → Editor** to customize templates, or insert any **Lumina** pattern from the block inserter.

No plugins required. Google Fonts (Fraunces + Manrope) load automatically; the theme works offline with system fallbacks.

## Customization

- **Colors & fonts:** everything flows from `theme.json` — tweak the palette, type scale or spacing there.
- **Style variation:** switch to the **Noir** dark style from the Site Editor's Styles panel.
- **Block styles:** Lumina card (group), Lumina glow (button), Lumina rounded (image), Lumina pull quote (quote).
- **Front-end script:** `assets/js/theme.js` handles reveals, counters, and back-to-top — vanilla JS, no dependencies.
